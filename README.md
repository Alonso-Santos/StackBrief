# Selene Glow - Landing Page

Projeto de Marketing de Empresas (Prof. Israel) e Web Mobile 2.

## Como abrir
Abra o arquivo `index.html` no navegador. Não precisa instalar nada.

## Estrutura
- `index.html`: estrutura da página (HTML)
- `style.css`: estilos (CSS)
- `script.js`: interações e simulador (JavaScript)
- `imagens/`: logos, paleta, mockups e fotos dos produtos

## Regra de negócio do simulador
No `script.js`:
- `PERCENTUAL_ECONOMIA`: percentual de economia por frequência de retoques
- `LIMITE_GASTO_ALTO`: gasto mensal a partir do qual o perfil é "alto potencial"
Os valores são exemplos e devem ser alinhados com o Marketing.

## Menu de acessibilidade
Botão redondo no canto superior direito (logo abaixo do cabeçalho) (ícone de acesso universal). Ajustes: tamanho do texto, brilho, contraste,
escala de cinza, inverter cores, fonte legível, espaçamento do texto, negrito, destacar links, cursor grande e
pausar animações. As escolhas ficam salvas no navegador. Código em `script.js` (final do arquivo) e `style.css`.
